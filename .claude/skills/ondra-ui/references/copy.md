# Copy

## Voice

A sharp, experienced sales manager who respects your time. Plain, specific, calm. Dealer vocabulary: buyers, the lot, stock, test drive, video walkaround, service bay, deposit, trade-in, exporter, WhatsApp. Not "leads pipeline objects", not "omnichannel engagement".

## Rules

- Name things by what the dealer recognises: "Who gets which calls", not "Routing rules engine".
- Sentence case everywhere, including buttons and headings.
- Buttons say what happens: "Send reply", "Book test drive", "Approve 4 follow-ups". Never "Submit", "OK", "Yes".
- The same verb runs through the flow: "Approve" button, "Approved" toast.
- Errors: what failed, why if known, how to fix. No apology, no blame, no internal codes as the headline. "Couldn't send on WhatsApp: the 24-hour window closed. Send an approved template instead."
- Destructive actions name the object and the consequence: "Delete Chidi's profile and call recordings". Prefer Undo over confirmation.
- Empty states invite action: "No calls yet this week. Calls Ondra answers will show here."
- Loading names the real operation ("Transcribing call…"). Never invent progress percentages.
- Placeholders are examples, not labels. Every input has a visible label.
- Numbers, dates, currency through `Intl` (see `dashboard.md`). Write times the dealer's way: "2:14 am".
- Complete sentences for anything translatable; never build sentences from fragments.

## Banned

- Buzzwords: streamline, empower, supercharge, seamless, cutting-edge, next-generation, world-class, enterprise-grade, game-changer, revolutionise, unlock, leverage.
- "Bot", "chatbot", "virtual assistant" for the product. Say "Ondra" or "the agents".
- Aphoristic cadence repeated ("Not a feature. A platform."). One strong line per page, not five.
- Em-dash chains, "not X, but Y" framing, colon-then-reveal headlines, scare quotes.
- Claims without evidence: response times, percentages, customer counts, "trusted by".
- Middle-dot metadata strings in UI copy; lay the parts out instead.
